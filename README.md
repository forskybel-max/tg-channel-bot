# Telegram Channel Bot (Гайды + Воронка подписки + Витрина продаж)

Отдельный асинхронный Telegram-бот на **Aiogram 3.31+** и **Supabase (PostgreSQL)** с поддержкой новых инлайн-кнопок Telegram Bot API (`ButtonStyle`: синие, зеленые, красные кнопки + `CopyTextButton` копирование в 1 клик + `DisabledButton`).

## Что умеет бот
* **Бесплатные гайды и База знаний:** категории (папки) и прямые карточки материалов (PDF/архивы/видео/фото/тексты/ссылки). Все файлы хранятся через вечный `file_id` Telegram (не занимают место на сервере).
* **Обязательная подписка + Deep-links для постов:** для каждого материала бот генерирует прямую ссылку вида `https://t.me/ваш_бот?start=item_1` (копируется в 1 клик в админке). При переходе с поста бот проверяет подписку на канал и сразу выдает гайд.
* **Фундамент под продажи «на вырост»:**
  * Раздел платных продуктов сейчас по умолчанию скрыт (`🔴 Скрыт`), включается в 1 клик в `⚙️ Админ-панель -> Настройки`.
  * Любой материал переключается между **Бесплатным гайдом** и **Платным товаром** одной кнопкой.
  * **Telegram Stars (`XTR`)** — полная автовыдача после оплаты.
  * **Полуавтомат (СБП / Карта / USDT)** — реквизиты с кнопкой копирования, отправка скриншота чека админу и выдача доступа в 1 клик (`✅ Выдать доступ`).
* **Полноценная админка в чате (`/admin`):** добавление/редактирование гайдов, обложек, кнопок-копирок для промптов, статистика, рассылка по базе пользователей и обратная связь.

## Быстрый старт (за 3 минуты)

### 1. Создайте проект в Supabase
1. Зайдите на https://supabase.com и создайте бесплатный проект (придумайте пароль БД без спецсимволов `@` и `#`, либо закодируйте их).
2. Нажмите сверху кнопку **Connect** -> вкладка **Connection String (URI)**.
3. Выберите режим **Transaction pooler (port 6543)** или **Session pooler (port 5432)** — он работает по IPv4 везде (и локально, и на бесплатном Render).
4. Скопируйте строку вида `postgresql://postgres.xxxx:ВАШ_ПАРОЛЬ@aws-0-...pooler.supabase.com:6543/postgres`.
   *(Никакой SQL вручную запускать не нужно — бот сам создаст все таблицы при первом старте!)*

### 2. Заполните `.env`
Скопируйте `.env.example` в `.env` и пропишите:
* `BOT_TOKEN` — токен нового бота от `@BotFather`
* `ADMIN_IDS` — ваш числовой Telegram ID (можно узнать у `@userinfobot`)
* `DATABASE_URL` — строка из Supabase

### 3. Запуск
* **Локально на Windows:** запустите `start.bat` (или `.venv\Scripts\python.exe main.py`).
* **Настройка канала:** зайдите в бота, нажмите `/admin` -> **Настройки бота**, включите проверку подписки, перешлите любой пост из вашего канала (бот сам определит ID канала) и добавьте бота в администраторы канала.
